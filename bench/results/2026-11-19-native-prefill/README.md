# Turing Q5 原生 prefill A/B

2026-11-19 在 `10.100.3.3` 测试。模型是 Orca Qwen3.8-Flash-Next-Uncensored Q5_K_M。使用 8 张 RTX 2080 Ti，每张 22 GiB、250 W，按每卡 6 层分配，专家全驻留。两组使用同一个二进制和同一份服务配置，保留 3072-token prefill 分块、16 个并发槽、8 个 batch group 和原有 MTP。测试 API 只监听 `127.0.0.1:8080`。

候选 `bd3b7ac80` 基于现网 `2a409c93f`，回移上游 Turing 专家内核中的两组量化组合。gate/up 都是 Q5_K，down 有 24 层 Q5_1、24 层 Q8_0。`STRATA_PF_FUSED_SM75_KQ=0` 使用现有 MMQ，`=1` 让合格的长分块使用原生实现。较短或不满足条件的块仍有 MMQ 路径。[上游提交](https://github.com/Niko1221/Strata/commit/042f91a3ffa02d59c6b5ccb76879a1aea3cb2e54)

后续补测了两组 Q5 算子和八卡 100k 的关键路径。[算子与 Nsight 对照](PROFILE.md)

## 冷 prefill

| 提示 token | MMQ prefill | 原生 prefill | 吞吐变化 | API 首字（MMQ → 原生） |
| ---: | ---: | ---: | ---: | ---: |
| 2,048 | 1.588 s | 1.527 s | +4.02% | 1.617 → 1.556 s |
| 8,192 | 2.656 s | 2.608 s | +1.85% | 2.693 → 2.646 s |
| 26,000 | 4.421 s | 4.369 s | +1.20% | 4.482 → 4.435 s |
| 100,000 | 12.305 s | 12.125 s | +1.49% | 12.458 → 12.317 s |

每列用三轮中位数。吞吐变化按相同 token 数下的时长比计算。12 对提示的 SHA-256、token 用量和结束原因一致，缓存复用均为 0。12 对中有 8 对贪婪输出文本一致，其中 100k 有 2 对一致。这个样本不衡量输出质量。[MMQ 逐轮数据](raw/mmq-prefill.json) · [原生逐轮数据](raw/native-prefill.json)

两组权重的单卡数值对照均通过。相对 FP32，`Q5_K/Q5_1` 的相对 RMS 误差为 MMQ 1.226%、原生 1.234%，`Q5_K/Q8_0` 为 1.408%、1.411%。原生组的八张卡均有实际调用记录，覆盖两种量化组合。[数值测试输出](raw/native-kernel-parity.log) · [内核调用记录](raw/kernel-routes.log)

上游发布记录里，单张 2080 Ti 上的 Qwen3.6 UD-Q4_K_XL 在 26k 负载中比 0.1.60 中间版本快约 23%，比 0.1.58 MMQ 快 8.8%。本机的 Q5_K_M、专家全驻留、8 卡分层和分块大小都参与决定端到端收益。[上游测试](https://github.com/Niko1221/Strata/commit/042f91a3ffa02d59c6b5ccb76879a1aea3cb2e54)

## 测量方法

- 冷 prefill 使用 2048、8192、26000、100000 token 的合成提示，每个长度 3 轮。两组提示按 SHA-256 配对，每轮记录缓存复用、引擎 `prompt_ms`、API 首个内容事件和贪婪输出摘要。
- 短提示 decode 使用 16 路采样，每路上限 1024 token。先做 16 路预热。稳态速度取 16 个槽均在 decode 时的服务端实际输出 token 增量，整批速度包含首字等待和收尾。
- 混合测试在八路稳定 decode 后插入一个冷 100k，记录该请求的首字等待，以及八条已有请求在这段时间内最长的 SSE 内容事件间隔。
- 数值测试在该机器的一张 2080 Ti 上运行，覆盖 Q5_K/Q5_1、Q5_K/Q8_0 和各自的 FP32、MMQ 对照。[原始数据](raw/)

切换脚本使用当前目录的冷 prefill 程序和前一轮的两个并发测试程序。部署到测试机时，将这四个 Python 文件放在同一个实验目录。[切换脚本](run_ab.py) · [冷 prefill 程序](prefill_ab.py) · [并发测试程序](../2026-11-18-decode-throughput/)
