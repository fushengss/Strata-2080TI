Engine semantics
Prefill::run checks should_stop at chunk boundaries and returns false with err=cancelled (src/prefill/prefill.cpp:3388,7311). generate.cpp:13789 binds should_stop to stop_req. The reader records this false return as read_ok=0 (17736,17801); pump_ok is independent. After the reader is joined, failed pump or pipeline drain is still fatal (17811–17815), while a read failure propagates read_err (17835–17837). The outer prompt path treats a stopped read as cancelled only with the stop request or yield condition, and still rejects batch_fatal (18192–18205). Native PERF includes cancelled, actual read_n and produced_n (19771,19927–19938). Therefore read_ok=0 is not itself evidence of an engine fault under an intentional cancellation. It must not be globally permitted.

Minimum narrow harness semantics agreed for separate v4
1. Before the sole cancel request, begin a dedicated owned-log byte slice. Observe a uniquely identifiable still-open large reader from that slice, then close only that request's HTTP socket. Preserve the observation/shutdown race disclaimer.
2. Finish the cancel slice before issuing the normal reuse request. In that slice the only failed read must be the observed reader ID, with read_ok=0 and pump_ok=1. Keep every marker parsed and every ID uniquely paired. No other read/pump failure is exempt.
3. Bind the failure to exactly one complete native cancelled PERF line for the counted cancel prompt, occurring after that reader end and before the next reader begin. Require zero generated tokens, initial reuse zero, fresh extent equal to prompt count and actual read count in range. A free-floating cancelled substring is insufficient.
4. Require intentional API cancellation with no output chunks; cancel/reuse request hashes equal; reuse and all other six normal requests pass existing exact logical usage/output gates; closed seven-request set and server idle at end.
5. Only a fully validated admission-on report may authorize that one failed read ID. The runner independently recomputes approval and passes it to its global reader validator. Other suites, off arms, unmatched IDs, malformed markers, pump errors, CUDA errors, unsafe ownership/residency or nonzero source dispatch remain failures.
6. A read_ok=1 boundary race does not establish interrupted-reader coverage; keeping that case fail closed is acceptable. Do not claim immediate GPU cancellation or chunk-exact shutdown from this HTTP test.
